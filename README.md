# 🎙️ VoiceMailAssist

**Voice-Based Email & Messaging Assistant – Hands-Free Communication for All**

VoiceMailAssist is a web-based voice assistant that lets you manage your Gmail inbox and Telegram messages entirely through voice commands - no typing required. Designed for accessibility, multilingual support, and everyday productivity, it combines real-time speech recognition, AI-generated replies, and a secure admin dashboard into one seamless experience.

---

## 📌 Project Overview

VoiceMailAssist bridges the gap between voice technology and daily communication. Users can read emails, compose replies, create calendar events, and manage Telegram messages - all by simply speaking. The assistant understands natural language commands in English, Tamil, and Hindi, making it accessible to a wider audience.

This project was developed as part of the **Infosys Springboard Virtual Internship 6.0 (Batch 13)** under the theme of AI-powered assistive tools.

## ✨ Features

| Feature | Description |
|---|---|
| 🎙️ Always-On Microphone | Continuous voice listening mode - no button press needed |
| 📧 Real Gmail Voice Control | Read, reply, compose, and manage emails by voice |
| ✈️ Telegram Voice Control | Send and receive Telegram messages hands-free |
| 🤖 AI Reply Suggestions | Context-aware smart replies generated by AI |
| 🔒 Multi-Layer Security (PIN) | Voice PIN authentication to protect your account |
| 🌐 Multilingual Support | Works in English, Tamil, and Hindi |
| 🛡️ Admin Dashboard | Monitor usage, manage users, and configure settings |
